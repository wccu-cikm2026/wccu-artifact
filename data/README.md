# Data directory

This artifact includes `cooperbench_mini_sample.jsonl`, a tiny metadata sample
for smoke tests. Full CooperBench-derived experiment inputs are generated by
`scripts/prepare_cooperbench_data.sh` from a HuggingFace dataset, a local
CooperBench snapshot, or an already converted JSONL file.

Generated data directories under `data/$EXP_TAG/` should not be committed to the
anonymous source repository unless they are intentionally curated and checked for
license and anonymity constraints.
